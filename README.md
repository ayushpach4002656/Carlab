- Genuine WebGL 3D showroom using Three.js

- Rotate, zoom, auto-spin, reset and fullscreen
- Paint, suspension and wheel choices feed into the 3D scene
- Existing builder, scoring, battles, games, garage, XP, achievements and challenges retained
- SEO metadata and launch branding
- Privacy/About pages
- Monetization-ready partner placement (not activated)

The 3D archetypes are original generated assets and are NOT manufacturer digital twins. Do not describe them as official models.
