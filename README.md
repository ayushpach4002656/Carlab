# CarLab V1 — Launch Instructions

Files:
- index.html
- styles.css
- app.js

## Put CarLab online with GitHub Pages
1. Sign in to GitHub.
2. Click the + button, then New repository.
3. Repository name: carlab
4. Select Public.
5. Create repository.
6. Choose "uploading an existing file".
7. Upload index.html, styles.css, and app.js from this package.
8. Commit the files.
9. Open Settings in the repository.
10. Open Pages.
11. Under Build and deployment, choose "Deploy from a branch".
12. Select main and / (root), then Save.
13. Wait for GitHub to show the public Pages address.

Do not buy a domain yet. First prove that people use the site.
